# **App Name**: SheetSync Events

## Core Features:

- Fetch Event Data: Retrieve event data directly from the linked Google Sheet using its URL.
- Dynamic Schedule Display: Display events in a clear, sortable, and filterable schedule format.
- Event Filtering and Sorting: Allow users to filter events based on category, date, or other relevant criteria directly from the sheet. Also, users will be able to sort events to customize their view.
- AI-Powered Event Summarization: Utilize a tool to generate concise summaries of event descriptions to present key information quickly to the user. Useful for long event details stored in the Google Sheet.
- Real-time Updates: Implement a mechanism to automatically refresh event data whenever the linked Google Sheet is updated.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and reliability.
- Background color: Light gray (#F0F2F5) to ensure readability and a clean look.
- Accent color: Vibrant orange (#FF9800) for call-to-action buttons and highlights, drawing attention without overwhelming.
- Body and headline font: 'PT Sans', a humanist sans-serif combining a modern look with warmth and personality, ensuring readability and approachability.
- Use a clean, grid-based layout to present the schedule clearly. Prioritize important information, such as event titles and times.
- Incorporate simple, clear icons to represent event categories or types for quick visual identification.
- Implement subtle transitions and animations for a smooth user experience when loading data or interacting with the schedule.
